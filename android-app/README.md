# Home Nystagmus Monitor Android App

This folder contains the original Android application project.

## Open

Open this `android-app/` directory in Android Studio, wait for Gradle sync, then run the `app` module.

## Notes

- Main source: `app/src/main/java/com/kk/homenystagmusmonitor/`
- ONNX model asset: `app/src/main/assets/swinunet_web.onnx`
- The repository root still owns `server/` and `docs/`; they were not moved into this Android folder.
