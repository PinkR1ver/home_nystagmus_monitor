# OKN Animation

Static OKN stimulus page for normal-subject testing workflows.

## Local preview

```sh
python3 -m http.server 4173 --directory okn-animation
```

Open `http://127.0.0.1:4173/`.

## GitHub Pages deployment

To publish at `https://pinkr1ver.github.io/okn-animation/`, deploy this folder as the root of the `PinkR1ver/okn-animation` GitHub Pages repository.
