# BEFAST feature extraction literature demo

A nine-slide Chinese HyperFrames deck that turns selected BEFAST papers into
explainable feature-extraction demonstrations.

```bash
npm run check
npm run dev
```

Open the URL printed by `npm run dev`, then use the arrow keys. Click **Present**
or press `P` for presenter/audience mode. See `SOURCES.md` for paper, model, data
and licensing provenance.

For a concise Chinese speaker script, see `TALKING_GUIDE.md`.
